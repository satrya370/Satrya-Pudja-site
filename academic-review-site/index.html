Upload a paper. Get a structured review back — not just a summary that restates the abstract.

A standalone RAG application, not an n8n workflow: a journal PDF or DOCX gets segmented into classified sections, embedded per paragraph, and stored so its AI features — summarize, review, compare, and Q&A — retrieve deterministically first, and only fall back to semantic or full-text search when a section can't be located directly.

How it works

Upload & hybrid segmentation

A PDF or DOCX is parsed with pdf.js, with Azure Document Intelligence as OCR fallback for scanned pages. Multi-signal heading detection slices it into sections; anything ambiguous gets classified by an LLM instead of guessed at.

Per-paragraph embeddings

Every paragraph is embedded and stored alongside its classified section type in MongoDB — the structure that makes deterministic retrieval possible in the first place.

Three-tier retrieval, not pure vector search

For structured tasks, the system checks for a regex-matched section type first, falls back to semantic vector search second, and full-text search last. Pure vector search is reserved for open-ended Q&A, where there's no fixed section to target.

Feature-specific chains run on top

The retrieved sections feed dedicated prompt chains for summarizing, reviewing, or comparing — each one scoped to the fields that feature actually needs, not one generic "ask the AI about this paper" prompt.

What it does

Live

Structured summary

An 8-aspect academic summary table generated per journal, in Bahasa Indonesia — Abstract, Introduction, Research Objectives, Research Methods, Results, Discussion, Strengths, and Weaknesses, each aspect retrieved from its own classified section rather than one pass over the whole PDF.

Live

Structured review

A 9-field JSON review — journal title, authors, year and volume, research objectives, research subjects, research methods, research results, strengths, and weaknesses — each field pulled from the section it actually belongs to, not inferred generically from the abstract.

Live

Document Q&A

Ask a free-form question and get a streamed answer. Retrieval runs BM25 keyword search and vector search in parallel, merges them by reciprocal rank fusion, boosts by likely section, then reranks with an LLM cross-encoder before the answer is written.

Live

Multi-paper comparison

Deterministic retrieval pulls the methods and results sections from both journals, then a comparison prompt returns structured JSON: method similarities, method differences, result similarities, result differences, and an overall conclusion — not a free-text paragraph.

Live

Literature review export

Turn a reviewed paper into a narrative .docx export instead of copying fields out by hand — built on the docx npm package directly from the same structured review data, not a separate manual write-up.

Live

Listen to the summary

The generated summary is turned into a spoken script and rendered to audio, so a paper's key points can be reviewed while doing something else instead of only as text on screen.

Live

Citation enrichment

Pulls citation count, influential citation count, and citation intent from Semantic Scholar's public API, matched by DOI or title, so a paper's standing isn't limited to what's printed on the PDF itself.

In progress

Tag extraction & Mendeley sync
