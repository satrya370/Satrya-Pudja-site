Photograph a receipt. Get back a spreadsheet, not a pile of paper.

Upload a photo of a real receipt — creased, angled, printed on thermal paper that's already fading — and this pipeline reads it with AI vision, validates the result, and hands you back a structured Excel workbook or JSON. Built for the receipts people actually have, not clean sample scans.

How it works

Upload the photo

A phone photo of the receipt, plus optionally last time's Excel workbook if you want this one added to it instead of starting fresh.

AI vision reads it

Vendor, line items, and totals are extracted directly from the image — no manual typing, no template matching against a fixed receipt layout.

A repair pass checks the output

If the first extraction comes back malformed, a second pass repairs it before anything is returned — the same fail-closed pattern behind every pipeline on this site.

Excel or JSON comes back

A downloadable workbook for a person, or structured JSON if you're wiring this into something else.

Three processing modes

Balanced

The default. Extracts what it can confidently read and fills reasonable gaps — good for everyday receipts.

Strict

Only returns fields it's actually confident about, rather than guessing at anything blurry or ambiguous.

Inspect

Returns the raw extraction as JSON instead of a workbook — useful for checking exactly what the model saw before trusting it.
